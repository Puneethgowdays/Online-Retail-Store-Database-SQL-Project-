## 🎯 Overview

A **complete SQL-based retail database system** that simulates real-world e-commerce operations.

This project demonstrates **database design, relationships, and advanced SQL features** used in backend systems and data analysis.

---

## 🧱 Database Structure

The system includes the following tables:

- 🧑 Customers  
- 📦 Products  
- 🧾 Orders  
- 📄 Order_Items  
- 🗂️ Order_Log (Audit Table)  

---

## 🧠 Key Concepts Covered

### 🔹 Core SQL
- Table creation with primary & foreign keys  
- Data insertion  
- INNER JOIN operations  
- Aggregations (SUM, GROUP BY)  

### 🔹 Advanced SQL
- 📊 View → Daily sales summary  
- ⚙️ Stored Procedure → Customer order history  
- 🔁 Trigger → Automatic order logging  
- 📈 Analytical Queries:
  - Top customers  
  - Best-selling products  

---

## ⚙️ How to Run

1. Open your SQL tool:
   - MySQL Workbench  
   - PostgreSQL  
   - SQL Server  

2. Run the script:

```sql
retail_store.sql
````

3. The database, tables, and queries will be created automatically
